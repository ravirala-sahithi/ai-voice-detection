## 1. Project Abstract
The rapid proliferation of generative artificial intelligence and neural text-to-speech (TTS) voice cloning engines (such as ElevenLabs, Tortoise-TTS, and VALL-E) has made synthetic speech indistinguishable from authentic human voices. This poses grave security vulnerabilities, including authorized caller spoofing, voice phishing (vishing), CEO voice impersonation, and fraudulent biometric authentication bypass.

**VoiceGuard AI** is an enterprise-grade full-stack AI Voice Clone Detection System designed and implemented from scratch. It integrates a fine-tuned Hugging Face **Wav2Vec 2.0** neural architecture (`garystafford/wav2vec2-deepfake-voice-detector`) exposed through a high-performance **Python FastAPI** microservice, orchestrated by a robust **Java 17 / Spring Boot 3** backend with stateless **JWT & BCrypt** security, persistently stored across distributed **TiDB Cloud (Serverless MySQL)** with strict TLS encryption, and visualized through a modern, responsive **React 18 + Vite** dashboard.

---

## 2. Problem Statement
Synthetic audio manipulation algorithms exploit spectral formant inconsistencies that are imperceptible to the human ear. Traditional forensic analysis approaches rely on handcrafted acoustic features or fixed filters, failing to detect modern deepfake speech generated by transformer-based vocoders. Organizations lack centralized, auditable, and decoupled systems capable of:
1. Validating and ingesting multipart audio streams securely.
2. Normalizing diverse sample rates and channels into standardized neural representations.
3. Quantifying likelihood with calibrated uncertainty margins rather than binary false certainties.
4. Persisting tamper-evident historical audit records isolated per authorized user.

---

## 3. Objectives
- **End-to-End Deepfake Detection**: Provide automated classification of audio speech into `LIKELY_REAL`, `AI_GENERATED`, or `INCONCLUSIVE`.
- **Pretrained Acoustic Modeling**: Leverage `garystafford/wav2vec2-deepfake-voice-detector` for self-supervised acoustic feature extraction at 16,000 Hz.
- **Enterprise Decoupling**: Isolate computationally demanding ML inference in Python FastAPI from the transactional Spring Boot business logic.
- **Distributed Cloud Storage**: Enforce all transactional user and analysis persistence into TiDB Cloud Serverless using verified TLS connections.
- **Zero-Trust Security**: Implement BCrypt password hashing, HMAC-SHA256 JWT tokens, and strict per-user relational isolation.
- **Responsive UI/UX**: Provide an interactive web portal featuring waveform playback, live upload tracking, confidence gauges, and search/filter history tables.

## 7. TiDB Cloud Database Schema

Execute [`database/schema.sql`](file:///c:/Users/SAHITHI/OneDrive/Documents/Desktop/AI-Voice-Clone-Detection-System/database/schema.sql) in your TiDB Cloud SQL Editor:

```sql
CREATE DATABASE IF NOT EXISTS `voice_clone_detection`
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE `voice_clone_detection`;

-- Users Table
CREATE TABLE IF NOT EXISTS `users` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `name` VARCHAR(100) NOT NULL,
    `email` VARCHAR(150) NOT NULL UNIQUE,
    `password_hash` VARCHAR(255) NOT NULL,
    `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX `idx_users_email` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Audio Analysis Results Table
CREATE TABLE IF NOT EXISTS `analysis_results` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `user_id` BIGINT NOT NULL,
    `original_filename` VARCHAR(255) NOT NULL,
    `prediction` VARCHAR(50) NOT NULL,
    `real_probability` DOUBLE NOT NULL,
    `ai_generated_probability` DOUBLE NOT NULL,
    `confidence_percent` DOUBLE NOT NULL,
    `analyzed_duration_seconds` DOUBLE NOT NULL,
    `model_name` VARCHAR(100) NOT NULL,
    `created_at` TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT `fk_analysis_user` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE,
    INDEX `idx_analysis_user_id` (`user_id`),
    INDEX `idx_analysis_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 8. API Endpoint Documentation

### Authentication (`/api/auth`)
- `POST /api/auth/register` — Accepts `{ name, email, password }`. Hashes password with BCrypt and returns JWT.
- `POST /api/auth/login` — Accepts `{ email, password }`. Authenticates and returns JWT.
- `GET /api/auth/me` — Protected. Returns current user profile details.

### Voice Detection (`/api/voice`)
- `POST /api/voice/analyze` — Protected multipart upload (`file`). Forwards to Python AI model, saves to TiDB, and returns `AnalysisResponse`.
- `GET /api/voice/result/{id}` — Protected. Retrieves single analysis record belonging to the authenticated user.
- `GET /api/voice/history` — Protected. Retrieves entire analysis history of authenticated user ordered newest first.
- `DELETE /api/voice/history/{id}` — Protected. Deletes an individual record from TiDB.
- `GET /api/voice/dashboard` — Protected. Returns aggregated statistics (`totalAnalyzed`, `likelyRealCount`, `aiGeneratedCount`, `inconclusiveCount`, `recentAnalyses`).

### Python AI API (Port 8000)
- `GET /` — API metadata and model loading status.
- `GET /health` — Health check reporting status (`UP`), device (`cpu`/`cuda`), and model loaded status (`true`).
- `POST /detect` — Accepts multipart audio (`file`). Returns prediction, real probability, AI generated probability, confidence percent, and audio duration.

## 9. Decision Policy & Uncertainty Calibration

Rather than enforcing an arbitrary 50% binary split, VoiceGuard AI implements an explicit decision policy:
1. Model logits are converted into probabilities using Softmax: $P_{\text{real}}$ and $P_{\text{fake}}$.
2. Probability margin is computed: $\Delta = |P_{\text{fake}} - P_{\text{real}}|$.
3. **Inconclusive Threshold**: If $\Delta < 0.15$ or $\max(P_{\text{real}}, P_{\text{fake}}) < 0.55$, the prediction is categorized as `INCONCLUSIVE`.
4. Otherwise:
   - If $P_{\text{fake}} > P_{\text{real}} \implies$ `AI_GENERATED`
   - If $P_{\text{real}} > P_{\text{fake}} \implies$ `LIKELY_REAL`
5. Confidence percentage is mapped to the dominant class probability ($\max \times 100\%$).

## 12. Known Limitations & Research Boundaries
- **Compression Artifacts**: Aggressive MP3 compression (e.g. 64 kbps) can truncate high-frequency spectral bands, occasionally lowering model confidence.
- **Short Audio Clips**: Recordings under 0.5 seconds lack sufficient acoustic phonemes for reliable transformer attention analysis.
- **Microphone Background Noise**: Extreme environmental background noise can distort feature extraction.
- **Ethical Disclaimer**: Predictions represent model estimations and do not replace legal or certified forensic verification.
